## Наблюдения, влияющие на конфигурацию

- k3d 5.9.0 несёт встроенную версию k3s по умолчанию `v1.35.5-k3s1`. Она не
  совпадает с закреплённой, поэтому `--image` передаётся явно во всех командах.
- Helm major-версии — 4. Флаг `--atomic` в ней отсутствует. Во всём проекте
  применяется набор `--install --rollback-on-failure --wait=watcher --timeout`.
  В Helm 4 значение `--wait` по умолчанию — `hookOnly`, поэтому для ожидания
  готовности подов указывается `=watcher` явно.
- Версия k3d установлена скриптом `install.sh`, закреплённым на коммите
  `15dd1e2dbd62c53ed990fce9b7332335e8cb053c`. SHA-256 файла сверен с
  `git show <commit>:install.sh`; значения совпали.
- k3s устанавливается скриптом с коммита
  `4dedb15be78017a8ddd5b9e81acd44f3481078ed`, версия закреплена параметром
  установщика.
- Требование `python3.12-venv` в Ubuntu вынесено из системного Python отдельно:
  pip нельзя установить в системное окружение (политика PEP 668).
